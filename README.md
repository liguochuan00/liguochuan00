## 关于我

写了很多年代码，现在把大部分精力放在 AI Coding 和 Agent 工具上。日常在 Cursor、Claude Code、Codex 和 DeepSeek Harness 之间来回切换，越用越确信一件事：Agent 缺的往往不是能力，而是对项目的正确认知。

围绕这条线做了一些开源项目：**Flow2Spec** 把项目知识整理成可路由的知识库，让需求先对齐事实，再动手写代码；也为 **DeepSeek Harness** 写了连接器、技能中心、会话导入等插件，把 MCP、CLI 和 Agent Skills 接进日常工作流。方向是一致的——把重复的判断变成工具，把工具做成别人也能直接用的东西。

想聊聊 AI Coding、Agent 工程或开源，欢迎邮件交流：**[liguochuan25@gmail.com](mailto:liguochuan25@gmail.com)**
