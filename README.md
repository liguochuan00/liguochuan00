## 关于我

写了很多年代码，现在把大部分精力放在 AI Coding 和 Agent 工具上。日常在 Cursor、Claude Code、Codex 和 DeepSeek Harness 之间来回切换，越用越确信一件事：Agent 缺的往往不是能力，而是对项目的正确认知。

于是有了 **Flow2Spec** —— 一套面向 AI 编码工具的工作流层。它把项目知识整理成可路由的知识库：需求进来先对齐事实，再动手写代码。写代码的方式一直在变，好的工程习惯不会消失，只是换个方式存在。

想聊聊 AI Coding、Agent 工具，或者 Flow2Spec，欢迎邮件交流：**[liguochuan25@gmail.com](mailto:liguochuan25@gmail.com)**
